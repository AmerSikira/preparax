# Preparax downloads

Preparax arranges prepared PDF artwork on production plates and creates screen separations.

Download installers for Windows, macOS, and Linux from [Releases](https://github.com/AmerSikira/preparax/releases).

The first release is a manual-install beta. Read its release notes and choose the package for your operating system and processor. The source code is maintained separately; this public repository contains distribution information and release downloads.

Report beta feedback through [Issues](https://github.com/AmerSikira/preparax/issues).
